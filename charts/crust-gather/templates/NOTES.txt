crust-gather installed a one-shot Job:
  {{ include "crust-gather.fullname" . }}

This chart runs `crust-gather collect` as a one-shot Job. With `reference` set, the
Job collects the cluster snapshot and pushes it to the OCI reference below:

  {{ .Values.reference | default "<set .Values.reference>" }}

After the Job completes and the archive is available in the registry, serve it locally:

  docker run --rm -i -p 9095:9095 \
    -v "${KUBECONFIG:-$HOME/.kube/config}:/home/nonroot/.kube/config:rw" \
    {{ .Values.image.repository }}:{{ .Values.image.tag | default .Chart.AppVersion }} serve -r {{ .Values.reference | default "ttl.sh/my-cluster-snapshot:1h" }}{{ if .Values.token }} --token {{ .Values.token }}{{ end }}{{ if .Values.username }} --username {{ .Values.username }} --password {{ .Values.password }}{{ end }}{{ if .Values.ca_file }} --ca-file {{ .Values.ca_file }}{{ end }} &

Then point `kubectl` at the served snapshot:

  kubectl get ns
